# Data

Place the assessment-provided CSV files in this folder:

- `train_test.csv`
- `validation.csv`
- `validation_predictions_template.csv`
- `december_chart_inputs.csv`

These raw CSV files are excluded by `.gitignore` in this starter package to avoid publishing assessment data accidentally.

If you intentionally want the raw data in the public repository, remove the `data/*.csv` rule from `.gitignore` before committing.
